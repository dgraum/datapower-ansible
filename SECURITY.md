# Security

Do not open a public issue that contains a password, a private key, an export, or a vaulted file.

Write to David Grau Merconchini at david@gallorojo.com.mx. Include the collection version from `galaxy.yml` or `ansible-galaxy collection list gr.idg`, and enough detail to reproduce the problem without those secrets.

An export written on the controller is mode `0600`. Store it outside the repository.
